Chapter 9: Data Cleaning

Open in VS Code

Real data is messy. Names arrive in random capitalization, states are spelled five different ways, money has dollar signs in it, and dates come in every format people have ever invented. In this chapter you'll clean a deliberately messy file of fake customer records. You'll learn to:

  • profile a dataset to find problems

  • clean text: trimming, case, and collapsing spaces

  • standardize categories with pick

  • turn text into numbers safely with :::

  • parse dates in many formats with DuckDB's strptime family of functions

  • find and remove duplicates

  • put it all together in a clean, reusable source

The messy file

data/messy_customers.csv has 126 rows of fake customer data. Here are a few raw rows:

You can already spot a lot of trouble: inconsistent capitalization, extra spaces, five phone formats, ny vs CA vs California, dates in several formats (and sometimes missing), and prices with $ or USD attached.

Step 1: Load everything as text

If we let DuckDB guess the column types, it will guess wrong for some columns, or fail on a weird value. When cleaning, a safer start is to read every column as text (all_varchar = true) and convert columns ourselves. duckdb.sql("...") lets us use DuckDB's own read_csv function with any options we like:

source: raw_customers is duckdb.sql("""
  SELECT * FROM read_csv('data/messy_customers.csv', all_varchar = true)
""")

Step 3: Clean text

Malloy has the common string functions built in: trim(), lower(), upper(), length(), substr(), concat(), replace(), and more. For anything else, you can call any DuckDB function by adding ! and the return type after its name: regexp_replace!string(...).

📘 Malloy docs. Functions explains the function!type(...) syntax for database functions that aren't built in. See also DuckDB's text functions and regular expressions.

run: raw_customers -> {
  select:
    full_name
    name_trimmed is trim(full_name)
    name_one_space is regexp_replace!string(trim(full_name), r'\s+', ' ', 'g')
    name_lower is lower(regexp_replace!string(trim(full_name), r'\s+', ' ', 'g'))
    email
    email_clean is lower(trim(email))
  limit: 8
}

Step 4: Standardize categories with pick

pick is Malloy's version of SQL CASE. To standardize state names, first make the value uppercase, remove the spaces and periods, and then map each known variant to its 2-letter code:

run: raw_customers -> {
  extend: {
    dimension: state_key is upper(regexp_replace!string(state, r'[\s.]', '', 'g'))
    dimension: state_clean is state_key ?
      pick 'CA' when 'CA' | 'CALIF' | 'CALIFORNIA'
      pick 'TX' when 'TX' | 'TEXAS'
      pick 'NY' when 'NY' | 'NEWYORK'
      pick 'FL' when 'FL' | 'FLA' | 'FLORIDA'
      pick 'WA' when 'WA' | 'WASH' | 'WASHINGTON'
      pick 'OR' when 'OR' | 'ORE' | 'OREGON'
      pick 'UT' when 'UT' | 'UTAH'
      pick 'CO' when 'CO' | 'COLO' | 'COLORADO'
      else null
  }
  group_by: state_clean
  aggregate: row_count is count()
  nest: raw_spellings is {
    group_by: state
  }
}

WITH __stage0 AS (
  SELECT
    group_set,
    CASE WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('CA','CALIF','CALIFORNIA')) THEN 'CA' WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('TX','TEXAS')) THEN 'TX' WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('NY','NEWYORK')) THEN 'NY' WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('FL','FLA','FLORIDA')) THEN 'FL' WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('WA','WASH','WASHINGTON')) THEN 'WA' WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('OR','ORE','OREGON')) THEN 'OR' WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('UT','UTAH')) THEN 'UT' WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('CO','COLO','COLORADO')) THEN 'CO' ELSE NULL END as "state_clean__0",
    CASE WHEN group_set=0 THEN
      COUNT(1)
      END as "row_count__0",
    CASE WHEN group_set=1 THEN
      base."state"
      END as "state__1"
  FROM (
    SELECT * FROM read_csv('data/messy_customers.csv', all_varchar = true)
  ) as base
  CROSS JOIN (SELECT UNNEST(GENERATE_SERIES(0,1,1)) as group_set  ) as group_set
  GROUP BY 1,2,4
)
SELECT
  "state_clean__0" as "state_clean",
  MAX(CASE WHEN group_set=0 THEN "row_count__0" END) as "row_count",
  COALESCE(LIST({
    "state": "state__1"}  ORDER BY  "state__1" ASC NULLS LAST) FILTER (WHERE group_set=1),[]) as "raw_spellings"
FROM __stage0
GROUP BY 1
ORDER BY 2 desc NULLS LAST

Every row now maps to one of eight states, and the nest shows which raw spellings fed into each. Always check for leftovers. Ending a pick with else null means any variant you missed shows up as a null group instead of hiding.

Step 5: Text to numbers, safely

  1. Remove every character that isn't a digit or a period.

Step 6: Cleaning dates with DuckDB functions

Dates are the hardest part of data cleaning. Our signup_date column mixes five formats, plus blanks and N/A:

Example Format code
2024-01-06 %Y-%m-%d
03/14/2024 %m/%d/%Y
08-Mar-2024 %d-%b-%Y
May 05, 2024 %B %d, %Y
20240314 %Y%m%d

DuckDB has excellent functions for this, and Malloy can call all of them:

DuckDB function What it does
strptime(text, format) parse text into a timestamp. Errors if the text doesn't match.
try_strptime(text, format) same, but returns null if the text doesn't match
try_strptime(text, [fmt1, fmt2, ...]) tries each format in order and uses the first one that works
strftime(time, format) format a time as text, e.g. '%A, %B %-d' → "Saturday, January 6"
make_date(y, m, d) build a date from three numbers
to_timestamp(seconds) convert a Unix epoch (seconds since 1970) to a timestamp

The format codes: %Y 4-digit year, %m month number, %d day, %b short month name (Mar), %B full month name (March), %H:%M:%S time, %A weekday name.

Other date shapes you'll meet

Dates show up in other odd shapes too. Here are three common ones, built from a tiny inline table: an Excel serial number (days since 1899-12-30), a Unix epoch (seconds since 1970-01-01), and separate year, month, and day columns:

run: duckdb.sql("""
  SELECT * FROM (VALUES ('45365', '1710374400', '2024', '3', '14'))
    AS t(excel_serial, unix_epoch, yr, mo, dy)
""") -> {
  select:
    from_excel is @1899-12-30 + excel_serial:::number days
    from_epoch is to_timestamp!timestamp(unix_epoch:::number)
    from_parts is make_date!date(yr::"BIGINT", mo::"BIGINT", dy::"BIGINT")

Be careful with fallbacks. Replacing a missing label with 'unknown' is helpful. Replacing a missing number with 0 usually is not, because it drags averages down. Leave unknown numbers null. Malloy's aggregates skip nulls.

Step 9: Putting it together in a clean source

We've been testing each fix inside a query. Now move them all into one source that reads the file without duplicates, so every query gets clean data. Notice that the dimensions can refer to each other:

source: customers is duckdb.sql("""
  SELECT DISTINCT * FROM read_csv('data/messy_customers.csv', all_varchar = true)
""") extend {
  dimension:
    customer_key is customer_id::number
    name is regexp_replace!string(trim(full_name), r'\s+', ' ', 'g')
    email_clean is lower(trim(email))
    phone_digits is regexp_replace!string(phone, r'[^0-9]', '', 'g')
    phone_clean is pick substr(phone_digits, 2) when length(phone_digits) = 11 else phone_digits
    state_key is upper(regexp_replace!string(state, r'[\s.]', '', 'g'))
    state_clean is state_key ?
      pick 'CA' when 'CA' | 'CALIF' | 'CALIFORNIA'
      pick 'TX' when 'TX' | 'TEXAS'
      pick 'NY' when 'NY' | 'NEWYORK'
      pick 'FL' when 'FL' | 'FLA' | 'FLORIDA'
      pick 'WA' when 'WA' | 'WASH' | 'WASHINGTON'
      pick 'OR' when 'OR' | 'ORE' | 'OREGON'
      pick 'UT' when 'UT' | 'UTAH'
      pick 'CO' when 'CO' | 'COLO' | 'COLORADO'
      else null
    plan_clean is concat(upper(substr(trim(plan), 1, 1)), lower(substr(trim(plan), 2)))
    signup is try_strptime!timestamp(
      signup_date, ['%Y-%m-%d', '%m/%d/%Y', '%d-%b-%Y', '%B %d, %Y', '%Y%m%d']
    )::date
    # currency
    first_purchase_amount is regexp_replace!string(first_purchase, r'[^0-9.]', '', 'g'):::number

  measure:
    row_count is count()
    customer_count is count(customer_key)
    # currency
    avg_first_purchase is first_purchase_amount.avg()
}
run: customers -> {
  aggregate: row_count, customer_count

  SELECT
    group_set,
    CASE WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('CA','CALIF','CALIFORNIA')) THEN 'CA' WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('TX','TEXAS')) THEN 'TX' WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('NY','NEWYORK')) THEN 'NY' WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('FL','FLA','FLORIDA')) THEN 'FL' WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('WA','WASH','WASHINGTON')) THEN 'WA' WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('OR','ORE','OREGON')) THEN 'OR' WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('UT','UTAH')) THEN 'UT' WHEN ((UPPER(regexp_replace(base."state",'[\s.]','','g'))) IN ('CO','COLO','COLORADO')) THEN 'CO' ELSE NULL END as "state_clean__0",
    CASE WHEN group_set=0 THEN
      count(distinct (CAST(base."customer_id" AS double precision)))
      END as "customer_count__0",
    CASE WHEN group_set=0 THEN
      AVG((TRY_CAST((regexp_replace(base."first_purchase",'[^0-9.]','','g')) AS double precision)))
      END as "avg_first_purchase__0",
    CASE WHEN group_set=1 THEN
      CONCAT(UPPER(SUBSTR(TRIM(base."plan"),1,1)),LOWER(SUBSTR(TRIM(base."plan"),2)))
      END as "plan_clean__1",
    CASE WHEN group_set=1 THEN
      count(distinct (CAST(base."customer_id" AS double precision)))
      END as "customer_count__1"
  FROM (
    SELECT DISTINCT * FROM read_csv('data/messy_customers.csv', all_varchar = true)
  ) as base
  CROSS JOIN (SELECT UNNEST(GENERATE_SERIES(0,1,1)) as group_set  ) as group_set
  GROUP BY 1,2,5
)
SELECT
  "state_clean__0" as "state_clean",
  MAX(CASE WHEN group_set=0 THEN "customer_count__0" END) as "customer_count",
  MAX(CASE WHEN group_set=0 THEN "avg_first_purchase__0" END) as "avg_first_purchase",
  COALESCE(LIST({
    "plan_clean": "plan_clean__1", 
    "customer_count": "customer_count__1"}  ORDER BY  "customer_count__1" DESC NULLS LAST) FILTER (WHERE group_set=1),[]) as "by_plan"
FROM __stage0
GROUP BY 1
ORDER BY 2 desc NULLS LAST

Saving the cleaned data

To save the clean table as a Parquet file, run the clean query's SQL through DuckDB. You can see that SQL with the SQL button on any result. Or do the cleaning in Python with the same functions, using the pattern from Chapter 7:

import duckdb
duckdb.sql("""
  COPY (
    SELECT DISTINCT
      customer_id::INTEGER                                        AS customer_id,
      regexp_replace(trim(full_name), '\\s+', ' ', 'g')           AS name,
      lower(trim(email))                                          AS email,
      try_strptime(signup_date,
        ['%Y-%m-%d','%m/%d/%Y','%d-%b-%Y','%B %d, %Y','%Y%m%d'])::DATE AS signup,
      TRY_CAST(regexp_replace(first_purchase, '[^0-9.]', '', 'g') AS DOUBLE) AS first_purchase
    FROM read_csv('data/messy_customers.csv', all_varchar = true)
  ) TO 'data/customers_clean.parquet' (FORMAT parquet, COMPRESSION zstd)
""")

Key takeaways

  • Profile first. Group by each column and count before you change anything.

  • Read messy CSVs with all_varchar = true, then convert each column yourself.

  • Call any DuckDB function with function_name!return_type(...), for example regexp_replace!string(...) or try_strptime!timestamp(...).

  • Use pick ... else null to standardize categories, and check for leftovers.

  • Use ::: (safe cast) to turn text into numbers. Bad values become null instead of errors.

  • try_strptime(text, [list of formats]) parses mixed date formats. Watch out for ambiguous day/month orders.

  • Put all of your cleaning into one source so every query uses clean data.
